# Evidence protocol — bi_level_pepa

- Scope: bi-level PEPA formalization plus AIDE² empirical instantiations (P1 power, P2 falsification, P3 drill).
- Required provenance: model/version, data source and license, prompt/configuration, seed, fold, raw outputs, analysis script/hash, and deviations.
- Current package includes P1/P2/P3 artifacts but is not yet a single immutable manifest; empirical generalization and causal interpretations remain conditional.
- No human subjects or PII are used. dataset: disclosed benchmark/synthetic sources with per-file licenses; hardware/runtime: record in sealed run metadata.
