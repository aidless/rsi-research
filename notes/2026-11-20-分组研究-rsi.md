## 2. 核心结论清单（按价值排序，每条带锚点）

### C1. 自证问题的真正形态不是「循环论证」，而是四类**不经过循环**的攻击；NC 是四机制中最大威胁
`rsi-deep-papers-b.md:257-258`。循环论证只是最容易想到的那种；更危险的是：①乐观代理（判分器系统性高于真值）②判据信息暴露（inner 能读到评分标准）③提示可诱导（inner 能说服判分器）④上游权重污染（密封集已在预训练里被记住）。四条**都不需要形成闭环保**。
- 代理分藏住损害：`sufficiency 0.940` vs 真 `faithfulness 0.731→0.667`（n=96）——`rsi-deep-papers-b.md:72`；聚合 F1 0.779 最高但 `recall 0.965 / precision 0.702`，聚合分把逐点损害藏起来（`:75`）。
- 损害定律：`β+=1.81 (R²=0.94)`、`β−=0.77`、乐观 2.3×（`:73`）；但复测 PyTorch 量级**不复现**（+0.017..0.096 vs MLX +0.218±0.018，`:74`）——定律是 MLX 单平台的，不能当普适。
- 无锚仍塌：关掉 anchor guards 后 always-pass 臂塌缩，且 co-loop 任务分与真臂一样好 → **下游分无法认证 verifier**（`:21-22`、`:48`）。

### C2. 聚合闸存在**逐实例回归盲点**，且该判据已真实落地成代码门禁（本组唯一「笔记→代码」闭环实证）
- 理论侧：`paired_gate` 只算 `d_i` 的均值、方差、ESS、显著性，**从不检查是否有实例从正转负**；连续 reward 下表现「净均值正但逐点回退」，会被放行——`rsi-deep-papers-c.md:230-238`。迁移到 SWE-bench 后变成字面 compositional override（修 8 题弄坏 2 题仍过闸，`:232`）。
- 最小修补：`regressed = #(d_i < −tol)`，`tol = c × noise_floor`（c 取 1–2）——`rsi-deep-papers-c.md:270-272`。
- **实测已落地**：`rsi-agent/rsi_agent/gates.py:74` `paired_gate(...)` 签名含 `max_regression_burden: float = 0.25`；`:109-121` 实现 `if max_regression_burden is not None: neg_abs=sum(-d for d in deltas if d<0); pos_sum=...; burden=neg_abs/pos_sum; if burden>max: REGRESSION_BURDEN` 拒。注意 `is not None` 而非 truthiness——修掉了 `0.0` 被当 falsy 跳过零容忍设置的坑（该坑见 `MEMORY.md:1582`）。
- 标定依据：190 实例 +0.05 / 10 实例 −0.5 → `burden=0.526` 被拒；真提升 `worst d_i −0.902`、`n_neg 0~15`、`burden≤0.086`，故 0.25 留 3 倍余量（`MEMORY.md:1582`）。

### C3. 判断证据的第一问从「够不够」升级为「**是不是自证**」
`rsi-claim-audit.md:78` 原话：「从『证据够不够』升级到『证据是不是自证』——P1 是真证据，P2 是自证，P3 是合成演示」。

### C4. 递归没有消失，而是「从时间轴搬到选择轴」；主角是验证器的**判别力与候选独立性**，带宽只是必要非充分

### C6. 独立度塌缩是**凸的**，但中等相关区出现迁移红利——唯一实质修正

### C7. 私有 ≠ 密封：隔离级别必须显式标明，权重层可能早已不密封

- 结论：SP 的判据要写成「私有 + 不可变 + 可查语义 + fail-closed」才算 co-evolution-resistant，且**必须标明隔离级别**（接口级「私」可被 inner 工具突破）——`:49`、`:196`。

## 6. 可复用判据（能提炼成规则或门禁的）

按「可执行性 × 普适性」排序。前 6 条建议直接落成门禁或 skill 条目。

1. **自证三问（进 claim-check skill）**：①评分函数读了被评对象吗（同义反复）？②特征里含答案的直系派生量吗？③审计只记「改了什么」而不记「改后是否仍然成立」吗？任一命中 = 自证，不是证据。锚：`rsi-claim-audit.md:78`、`:24`。
2. **聚合闸的逐实例回归闸（已成门禁）**：`regressed = #(d_i < −tol)` 或 `burden = neg_abs/pos_sum > max_regression_burden` 即拒；`tol` 用 `noise_floor` 标定（c=1–2）；阈值参数字段用 `is not None` 判断（0.0 = 零容忍必须生效）。锚：`rsi-deep-papers-c.md:270-272`、`rsi-agent/rsi_agent/gates.py:109-121`。
3. **相关判定一律聚类 permutation，不池化**：按 task/seed 聚类做 sign-flip；池化 p 会把「同一任务的多个实例」当独立样本。锚：`rsi-deep-papers-b.md:20`（池化 0.014 假显著 vs 聚类 0.12）。
4. **fail-closed 而非降级**：「拿不到测量 → defer/拒」，不许退回弱闸（count-only）；沙箱/保护原语不可用同样是拒，不是降级。锚：`rsi-deep-projects-core.md:69`（`acceptance.py:159-166`）、`:158/:174`（RSIAgent）、`rsi-deep-projects-more.md:56`（meclaw「no path on which restricted profile quietly does nothing」）。
5. **密封必须封两层**：权重记忆（去污染证书：strict-match 探针 + hash 挂密封集 hash）+ 判据文本（对 inner 不可读）+ 隔离级别显式标注（接口级 ≠ OS 级）。锚：`rsi-deep-papers-b.md:129`、`:161`、`:196`。
6. **门要能红、且两个方向都测**：逐实例回归闸必须同时证明「真提升不被误杀」（burden≤0.086 留 3 倍余量）与「净涨逐点退必被拒」（0.526 被拒）。锚：`MEMORY.md:1582` + `rsi-deep-papers-c.md:230`。
7. **数字口径优先级**：hash 匹配 > words 近似；`mtime` 先后证「非循环」；每个数字带 as-of（star 数、版本号、数据集规模）。
8. **证据分级两轴不合并**：来源权威度（官方/一手/二手/博客）× 证据类型（可重跑实测/文档/访谈/转述）。「验号 PASS」只升来源轴，不升证据类型轴。锚：`rsi-failure-modes.md:84-91`。
9. **数据燃料四标准 + 两附加查**：①本机 CPU 可跑 ②免 key ③客观打分 ④能 split；附加：许可证风险（CC-BY-NC 要单独判）+ 噪声类型（二值 vs 连续决定能否进 ESS 闸）。锚：`rsi-deep-datasets.md:422-434`。

11. **能力扩张三分类**：better-search / internalization / frontier-expansion，只有第三类算能力扩张，且必须有逃逸见证；「检查搬家」不算扩张。锚：`rsi-deep-papers-b.md:195`、`:178`。
